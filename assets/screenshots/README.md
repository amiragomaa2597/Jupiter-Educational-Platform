## Privacy policy for this folder

Do **not** add images that show:

- Real student or parent names
- Phone numbers, emails, national IDs
- Payment amounts tied to real people
- Internal staff directories with personal data
- API keys, tokens, connection strings, or server admin panels with secrets

## Accepted practice

1. Use anonymized / synthetic data.
2. Crop or blur residual PII.
3. Prefer UI that demonstrates educational workflows (student hub, courses, homework, attendance).
4. Update the Screenshots section in the root `README.md` with markdown image links after review.
