## Concise CV bullets (3–5)

Use these as written, or lightly adapt to your CV voice:

- Built and maintained features for a production-oriented educational platform covering student hubs, course/batch management, enrollments, homework workflows, attendance, and certificates.
- Developed full-stack solutions with **Angular** (SPA, role-based routing, bilingual EN/AR UI) and **ASP.NET Core** REST APIs secured with **JWT** and permission-based authorization.
- Modeled and evolved educational domain data in **SQL Server** using **Entity Framework Core** (courses, batches, enrollments, quizzes/questions, attendance, certificates).
- Implemented and integrated realtime and operational concerns including **SignalR** (quiz participation / notifications), email, and notification delivery patterns within a modular API architecture.
- Contributed to architecture improvements by working within a layered modular monolith (API / Application / Infrastructure / Domain) while maintaining and extending an existing system.
